02

Module core/

core.py — Classe Game

Représente l'état complet d'une partie en cours. Gère la position du joueur selon les coups et le moteur physique.

Attributs
position_x, position_yPosition actuelle du mouton
vitesse_x, vitesse_yVitesse courante
nb_jumpNombre de sauts effectués (score)
objectifListe de deux points [(x1,y1),(x2,y2)]
lst_blocsListe des objets Bloc du niveau
themeThème visuel du niveau
pas()

Avance la simulation d'un pas physique. Applique la gravité, détecte les collisions sur X puis sur Y, gère les comportements spéciaux (glace, colant, élastique, trampoline, dérapé). Retourne "Finish" quand le mouton s'arrête.

detection_colision(coin_sup_gauche, coin_inf_droit)

Vérifie si la position actuelle du mouton est à l'intérieur d'un rectangle défini par deux coins. Retourne un booléen.

en_collision()

Methode parcourant l'ensemble des blocs du niveau à chaque pas. Fait appel à la méthode detection_colision(coin_sup_gauche, coin_inf_droit) pour chaque bloc. Si une colision est détécté dans le pas, renvoie le type de bloc rencontré. Sinon, renvoie None.

is_winnable()

Vérifie si le mouton est actuellement dans la zone objectif. Utilisé à chaque pas dans mouvement() pour détecter la victoire immédiatement.

lire_fichier_niveau()

Méthode permettant de lire toutes les informations texte du niveau. Stock les informations dans une liste de liste non trié.

ranger_donnees()

Utilise la méthode lire_fichier_niveau() afin de ranger les données reçus dans les attributs de notre classe principal, "Jeu".

clic_vers_vitesse(clic)

Convertit un clic souris en vecteur vitesse. Calcule la direction vers le clic, et plafonne la norme à VMAX si le clic est trop loin. Retourne le point d'arrivée visuel de la flèche.

core.py — Classe Bloc

coin_sup_gaucheCoin haut-gauche (x, y)
coin_inf_droitCoin bas-droit (x, y)
typenormal, glace, derape, colant, elastique, trampoline
styleThème visuel du bloc (foret, desert...) ou "custom"
03

Module gui/

interface.py — Affichage

charger_niveau(skin, jeu, theme, mise_a_jour_auto, dessiner_perso)

Redessine complètement le niveau : fond, parois, blocs (avec détection automatique orientation horizontale/verticale), objectif et personnage. Paramètres optionnels pour le solveur qui n'a pas besoin de mise à jour visuelle.

mouvement(jeu, skin, theme, trace)

Boucle d'animation principale. À chaque itération : vérifie la victoire, appelle jeu.pas(), met à jour l'affichage, enregistre la trace. Bloque l'interface pendant l'animation via STATUE_JEU. Retourne "GAGNE" ou None.

rafraichir_editeur(etat_editeur)

Redessine l'éditeur complet : fond, murs, tous les blocs (image ou rectangle selon le format), objectif, départ, et panneau de boutons avec indicateurs de sélection.

charger_editeur_depuis_fichier(chemin)

Lit un fichier .txt et reconstruit la structure dictionnaire de l'éditeur. Détermine l'orientation des blocs image par comparaison largeur/hauteur et charge le bon chemin d'image avec suffixe _v si vertical.

gestion.py — Gestion des clics

Chaque menu du jeu a une fonction clic_xxx dédiée. gestion_clique() dispatche vers la bonne fonction selon etat.menu.

clic_principalMenu principal : skin, thème, éditeur
clic_jeuVise et prépare le saut
clic_pauseReprendre, solveur, sauvegarder
clic_solveurLance profondeur, largeur ou glouton
clic_editeurListe des niveaux : modifier, supprimer, créer
clic_editeur_nvÉditeur de niveau : boutons du panneau et canvas
clic_gagneÉcran de victoire : retour au menu

sauvegarde.py

sauvegarder_niveau(etat_editeur, theme_choisi, nom_fichier=None)

Écrit le niveau au format standard. Si nom_fichier est donné, écrase le fichier existant ; sinon génère un nouveau nom numéroté. Calcule les coordonnées réelles de chaque bloc à partir de son centre et de ses dimensions taille_l / taille_h.

05

Format des fichiers niveau

Chaque niveau est un fichier .txt structuré ainsi :

# Ligne 1 : position de départ
400,300

# Ligne 2 : zone objectif (x1,y1,x2,y2)
100,200,200,300

# Ligne 3 : thème visuel
foret

# Lignes suivantes : blocs (x1,y1,x2,y2,type,theme)
189,420,339,460,normal,desert
441,241,591,281,glace,foret
517,407,557,507,normal,foret # bloc vertical (hauteur > largeur)
  • Le thème de la ligne 3 peut valoir foret, desert, espace, pirate ou none.
  • Le theme de chaque bloc peut valoir un thème visuel ou custom pour un rectangle sans image.
  • L'orientation d'un bloc image est déduite automatiquement : si hauteur > largeur → vertical.
06

Algorithmes de résolution

Recherche en profondeur
Naïve — DFS

Utilise une pile. Explore un chemin jusqu'au bout avant d'en essayer un autre. Ne garantit pas la solution la plus courte. Rapide à démarrer mais peut s'égarer longtemps dans de mauvaises directions.

Structure : Pile
Recherche en largeur
Optimale — BFS

Utilise une file. Explore tous les chemins de longueur N avant ceux de longueur N+1. Garantit la solution avec le minimum de sauts. Plus lente sur les niveaux complexes.

Structure : File

Paramètres communs
